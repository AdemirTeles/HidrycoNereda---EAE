Abstract

The HeartBeat block is used to monitor the communication between the PLC and the Nereda controller.

Description

Description :

Communication between the Nereda® Controller and PLC will be monitored by means of a watchdog signal. The control system initiates the first watchdog signal and sends a Boolean signal to the Nereda® Controller.

The HeartBeat block will receive a Boolean signal of 0 or 1 from the Nereda® Controller, and then the HeartBeat block will check the value received from the Nereda® Controller and send back the inverse bit (if the Nereda® Controller sends 1, the HeartBeat will send 0, and vice versa). Every time, the Nereda® Server will send back the same value that the HeartBeat block sent.

In case the HeartBeat does not receive the same value that it sent to the Nereda® Controller within a predefined adjustable ‘watchdog’ time, it will generate a communication failure.

If the Nereda® process control is in "Auto" mode, the emergency recipe is automatically started for each reactor for which the emergency recipe is set to ‘On’. After watchdog communication is restored, the Nereda® process control mode must be switched back to "Auto" or "Manual" by the operator. This is not an automatic action from the process automation system or the Nereda® Controller.
