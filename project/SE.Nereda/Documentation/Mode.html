Abstract

Mode is the block that allows the selection of the operating mode (Automatic, Manual, Emergency) as well as resetting the reactors through the HMI. This Mode block is also connected to the HeartBeat to receive the command to activate Emergency mode in case of a loss of connection between the PLC and the Nereda® Controller.

Mode Representation :


Input Adapters :
Name Adapter Description
IHeartBeat


It gives the state of the connection between the PLC and the Nereda® Controller through the variable EmergencyOn :

  • EmergencyOn = TRUE : the connection is lost.

  • EmergencyOn = FALSE : the connection is good.
