Description

For each reactor, the scheduler maintains a TimeSinceStartFeed value.

This timer runs continuously for each reactor and is reset whenever the corresponding reactor enters the Starting state of the Feed phase.

Example:

  • Reactor 1: 125 min

  • Reactor 2: 5 min

  • Reactor 3: 65 min

2. Feed Order

The reactors are ordered according to their TimeSinceStartFeed.

The reactor with the highest TimeSinceStartFeed receives the highest feeding priority, because it is the reactor that has been waiting the longest since its previous Feed phase.

This ensures that the reactor which has had the longest available treatment time is selected first.

Example:

<div><div><div><div><div><div><div>
TimeSinceStartFeed:
R1 = 125 min
R2 =   5 min
R3 =  65 min
</div></div></div><div><div></div></div></div></div></div></div>

Sorted from highest to lowest:

<div><div><div><div><div><div><div>
125 → 65 → 5
</div></div></div><div><div></div></div></div></div></div></div>

Therefore, the feed order is:

<div><div><div><div><div><div><div>
R1 → R3 → R2
</div></div></div><div><div></div></div></div></div></div></div>

Queue positions:

<div><div><div><div><div><div><div>
R1 = 0
R3 = 1
R2 = 2
</div></div></div><div><div></div></div></div></div></div></div>

3. Feed Interval and Actual Cycle Time

The nominal Feed Interval is calculated from the configured nominal cycle time and the total number of reactors:

<div><div><div><div><div><div><div>
FeedInterval = NominalCycleTime / NumberOfReactors
</div></div></div><div><div></div></div></div></div></div></div>

The Feed Interval remains unchanged when a reactor becomes unavailable, aborts, or is deselected.

Instead, the Actual Cycle Time is reduced according to the number of available reactors:

<div><div><div><div><div><div><div>
ActualCycleTime =
NominalCycleTime ×
(NumberOfAvailableReactors / NumberOfReactors)
</div></div></div><div><div></div></div></div></div></div></div>

The Feed Interval can also be calculated from the Actual Cycle Time:

<div><div><div><div><div><div><div>
FeedInterval =
ActualCycleTime / NumberOfAvailableReactors
</div></div></div><div><div></div></div></div></div></div></div>

Both calculations result in the same Feed Interval.

Example:

<div><div><div><div><div><div><div>
NominalCycleTime = 300 min
NumberOfReactors = 3
</div></div></div><div><div></div></div></div></div></div></div>

Therefore:

<div><div><div><div><div><div><div>
FeedInterval = 300 / 3
             = 100 min
</div></div></div><div><div></div></div></div></div></div></div>

If one reactor becomes unavailable:

<div><div><div><div><div><div><div>
NumberOfAvailableReactors = 2
</div></div></div><div><div></div></div></div></div></div></div>

Then:

<div><div><div><div><div><div><div>
ActualCycleTime = 300 × (2 / 3)
                = 200 min
</div></div></div><div><div></div></div></div></div></div></div>

And:

<div><div><div><div><div><div><div>
FeedInterval = 200 / 2
             = 100 min
</div></div></div><div><div></div></div></div></div></div></div>

Therefore, the Feed Interval remains 100 minutes, while the Actual Cycle Time becomes shorter.

4. Plant Next Feed Horizon

The NextFeedHorizon represents the remaining time before the next Feed phase must start in the plant.

It is calculated using the lowest TimeSinceStartFeed among the reactors currently participating in the feed schedule:

<div><div><div><div><div><div><div>
NextFeedHorizon =
FeedInterval - LowestTimeSinceStartFeed
</div></div></div><div><div></div></div></div></div></div></div>

Example:

<div><div><div><div><div><div><div>
TimeSinceStartFeed:
125 min
5 min
65 min
</div></div></div><div><div></div></div></div></div></div></div>

The lowest value is:

<div><div><div><div><div><div><div>
LowestTimeSinceStartFeed = 5 min
</div></div></div><div><div></div></div></div></div></div></div>

With:

<div><div><div><div><div><div><div>
FeedInterval = 100 min
</div></div></div><div><div></div></div></div></div></div></div>

The result is:

<div><div><div><div><div><div><div>
NextFeedHorizon = 100 - 5
                = 95 min
</div></div></div><div><div></div></div></div></div></div></div>

Therefore, the next Feed phase must start in 95 minutes.

5. Next Feed Horizon per Reactor

Each reactor receives its own NextFeedHorizonReactor according to its position in the Feed queue.

The calculation is:

<div><div><div><div><div><div><div>
NextFeedHorizonReactor =
NextFeedHorizon +
(FeedInterval × QueuePosition)
</div></div></div><div><div></div></div></div></div></div></div>

Using the previous example:

<div><div><div><div><div><div><div>
FeedInterval = 100 min
NextFeedHorizon = 95 min
</div></div></div><div><div></div></div></div></div></div></div>

Feed queue:

<div><div><div><div><div><div><div>
R1 = Position 0
R3 = Position 1
R2 = Position 2
</div></div></div><div><div></div></div></div></div></div></div>

Therefore:

<div><div><div><div><div><div><div>
R1 = 95 + (100 × 0)
   = 95 min

R3 = 95 + (100 × 1)
   = 195 min

R2 = 95 + (100 × 2)
   = 295 min
</div></div></div><div><div></div></div></div></div></div></div>

6. Interface with Reactor Fallback Control

The scheduler sends the calculated NextFeedHorizonReactor to each reactor instance.

Each reactor instance sends its current availability status back to the scheduler.

The scheduler uses this information to determine:

<div><div><div><div><div><div><div>
NumberOfAvailableReactors
</div></div></div><div><div></div></div></div></div></div></div>

and to update the Feed queue, Actual Cycle Time, and Next Feed Horizon accordingly.
