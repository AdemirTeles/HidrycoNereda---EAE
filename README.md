# Starter_Template
Template to be used as starting point in any new repository


# Before you begin
We assume basic know-how with Git. If you don't have that know-how (yet), we recommand you use Github Desktop.

# How to use
From this page hit the "Use this template button" and follow the instructions. 

## If you are starting the project
The default template is a v26.0 Starter Kit for Multi OS. 
You will need to rename the solution in EAE based on your needs.

## If you already have the project
Replace the content of the project folder.
After confirmation you will be redirected to your newly created Github repository. You can open it locally by hitting the "Code" button as shown below.
